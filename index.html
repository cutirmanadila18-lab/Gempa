Dokumentasi & Tester Fetch API Kualitas Udara

Sama persis seperti pada PDDIKTI, kamu bisa memanggil file API ini secara langsung di JavaScript menggunakan fetch():

GET
Contoh Pemanggilan di JavaScript (Frontend) 
// Mengambil data kualitas udara IQAir:
fetch('api.php')
  .then(res => res.json())
  .then(data => {
    console.log('Kota Terpolusi:', data.data.ringkasan.kotaTerpolusi.kota);
    console.log('AQI:', data.data.ringkasan.kotaTerpolusi.aqi);
    console.log('PM2.5:', data.data.ringkasan.kotaTerpolusi.polutan.pm25);
  });
Output Respon (JSON) 200 OK 0 ms

Apa Itu PM2.5?

PM2.5 adalah partikel mikroskopis di udara yang berdiameter lebih kecil dari 2.5 mikron (sekitar 30x lebih kecil dari sehelai rambut).

Partikel ini dapat menembus saluran napas hingga masuk ke paru-paru dan peredaran darah, terutama bersumber dari emisi kendaraan bermotor dan pembakaran industri.
